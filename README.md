# 全国农机补贴数据大屏 · 田间监测与作业监控设备

基于全国农机购置与应用补贴信息公开平台（各省公示系统）公开数据构建的可视化大屏。

## 在线访问

https://sky9606.github.io/agri-subsidy-dashboard/

## 数据口径

- 补贴机具范围：田间监测及作业监控设备（品目代码 07）
- 时间范围：2021–2026（2026 年数据截至 10 月）
- 样本规模：515,981 条购机记录 / 543,949 台套 / 销售额 63.19 亿元 / 补贴 24.43 亿元
- 覆盖：26 个省级单元、2,102 个区县、14,425 个乡镇、10,229 家经销商
- 省级单元已合并北大荒农垦、新疆生产建设兵团、广东农垦、计划单列市（厦门/宁波/大连/青岛）等独立公示口径
- 销售额 = 单台销售价格 × 购买数量
- 购机者姓名、电话、身份证、门牌号等个人信息全部不展示，仅做区域统计

## 功能

- 全国 → 省 → 区县 → 乡镇 四级下钻（地图、排行、表格均可点击）
- 年份分段筛选（全部 / 2021–2026）、销量与销售额指标切换
- 顶部核心指标、品目结构、价格带分布、厂家市占率、区域排行、月度趋势、多维明细表
- **关键字搜索**：顶栏搜索框（快捷键 `/` 或 `Ctrl+K`），覆盖厂家 / 型号 / 品目 / 省 / 区县 / 乡镇 / 经销商
  - 结果按匹配质量（全等 → 前缀 → 包含）与销量排序，分组显示并高亮命中词
  - 点省份 / 区县 / 乡镇 → 直接下钻；点经销商 → 定位到所在省并切到经销商表
  - 点厂家 / 型号 / 品目 → 弹出详情卡（累计销量、销售额、均价、覆盖省份、逐年销量、分省 TOP6，分省条目可点击下钻）
  - 索引由 `build_data.py` 预生成为 `data.js` 的 `search` 字段（约 1.1 MB，3 万条实体），前端本地匹配，无需服务端与额外请求

## 数据源限制（非漏抓）

- 山西省：接口 HTTP 500
- 湖北省、甘肃省：平台显示「数据维护中」
- 贵州省、西藏自治区：该品目各年无公示记录
- 黑龙江、重庆：年份下拉仅 2024–2026
- 2018–2020 旧系统链接已下线

## 技术说明

纯静态站点，无构建、无服务端。ECharts 5.5.1 + 原生 JS，1920×1080 固定舞台按窗口等比缩放。
地图边界来自 DataV GeoAtlas（含台湾、港澳、南海诸岛）。

## 本地更新

```bash
python ../scraper/daily_update.bat   # 每日抓取（Windows 计划任务 03:00）
python build_data.py                 # 重新聚合生成 data.js
```

## 重新发布

站点托管在 GitHub Pages（`main` 分支根目录），数据更新后重新发布即可，约 30 秒生效。日常无需手工操作，`scraper/daily_update.bat` 已包含重建与发布。

本机 `github.com:443` 常被代理拦截（`CONNECT tunnel failed, 502`），而 `api.github.com` 可用，所以 `scraper/daily_update.py` 的发布环节是两级：

1. 先 `git push`（正常时优先，保留完整 git 历史）
2. 失败则自动改用 GitHub API：比对索引 blob SHA 与远端 tree，只上传真正变化的文件，再 PATCH `main` 引用

发布走了哪条路、是否成功，都会写进 `data/daily_update.log`。若要手工重建：

```bash
python build_data.py          # 重新聚合生成 data.js
python ../scraper/daily_update.py   # 含发布（自动选 git 或 API）
```

查看构建状态：仓库 Actions 页签，或 `https://sky9606.github.io/agri-subsidy-dashboard/`
